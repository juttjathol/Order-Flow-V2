1 · Install & license انسٹال اور لائسنس

English

  1. Download the APK from the homepage on the Android phone that will be Main (the shop server).
  2. Allow installs from this site when Android asks.
  3. Open Order Flow → tap the WhatsApp button or paste your 16-character license key.
  4. The first phone that activates the key becomes Main — the key binds to it.
  5. Main runs the shop server on Wi-Fi port 8787. Keep the app open; do not swipe it away.
  6. Main works up to 48 hours offline after a valid check. If the key is revoked, Main locks and shows WhatsApp support.

اردو

  1. ہوم پیج سے APK اس اینڈرائیڈ فون پر ڈاؤن لوڈ کریں جو Main (دکان کا سرور) بنے گا۔
  2. اینڈرائیڈ پوچھے تو اس سائٹ سے انسٹال کی اجازت دیں۔
  3. آرڈر فلو کھولیں → واٹس ایپ بٹن دبائیں یا اپنی 16 حرفی لائسنس کی پیسٹ کریں۔
  4. جو پہلا فون کی ایکٹیویٹ کرے گا وہ Main بن جاتا ہے — کی اسی فون سے بندھ جاتی ہے۔
  5. Main وائی فائی پر پورٹ 8787 پر دکان کا سرور چلاتا ہے۔ ایپ کھلی رکھیں، بند نہ کریں۔
  6. درست تصدیق کے بعد Main آف لائن بھی 48 گھنٹے چلتا ہے۔ کی منسوخ ہو تو Main لاک ہو جاتا ہے اور واٹس ایپ سپورٹ دکھاتا ہے۔

2 · Stations & roles اسٹیشنز اور کردار

English

Other phones on the same Wi-Fi join free — they do not need a key.

  1. On the new phone: License screen → Connect to Main.
  2. Type the IP shown on Main's Home screen, or scan the QR code.
  3. Pick a role: Manager, Order taker, Kitchen, Cashier, Stock clerk, Front desk, Specialist, Driver.
  4. Each station has its own queue and syncs live with Main. If the connection drops, the station queues its work and flushes when Main is reachable.
  5. Switch roles anytime from a station with the logout button, or cover any role from Main's account-switch menu.

اردو

اسی وائی فائی پر موجود دوسرے فون مفت جڑتے ہیں — انہیں کی کی ضرورت نہیں۔

  1. نئے فون پر: لائسنس اسکرین → Connect to Main دبائیں۔
  2. Main کی ہوم اسکرین پر دکھایا گیا IP لکھیں، یا QR سکین کریں۔
  3. کردار منتخب کریں: مینیجر، آرڈر ٹیکر، کچن، کیشیئر، اسٹاک کلرک، فرنٹ ڈیسک، اسپیشلسٹ، ڈرائیور۔
  4. ہر اسٹیشن کی اپنی قطار ہے اور Main سے لائیو جڑتا ہے۔ رابطہ ٹوٹے تو کام قطار میں جمع رہتا ہے اور Main ملتے ہی بھیج دیا جاتا ہے۔
  5. کسی بھی اسٹیشن سے لاگ آؤٹ کر کے کردار بدلیں، یا Main کے اکاؤنٹ مینو سے کوئی بھی کردار سنبھالیں۔

3 · Business models کاروباری ماڈل

English

More → Business model (Main only). The app reshapes itself for each business:

  • Restaurant — table map, kitchen tickets, courses (starter / main / dessert), reservations.
  • Retail — register queue, SKU barcode scanning, stock cards, quick retail sale.
  • Fast food — queue numbers, takeaway, kitchen fire.
  • Services — appointments, specialists, service menu with duration.

Changing the model keeps your menu, stock and customers.

اردو

  • ریسٹورنٹ — ٹیبل نقشہ، کچن ٹکٹ، کورسز (اسٹارٹر / مین / ڈیزرٹ)، ریزرویشن۔

  • سروسز — اپائنٹمنٹ، اسپیشلسٹ، دورانیے کے ساتھ سروس مینیو۔

ماڈل بدلنے سے مینیو، اسٹاک اور کسٹمر محفوظ رہتے ہیں۔

4 · Menu & modifiers مینیو اور موڈیفائر

English

  1. New in 1.1.65 — Menu Scan: Menu tab → scanner icon → take a photo of the menu (or upload a menu PDF). Names, prices and categories are read on the phone itself — no internet, nothing uploaded anywhere.
  2. v1.1.70 — imports no longer dead-end: a price in the middle of a row (size or unit after it) no longer loses the item, and when a page's price style can't be matched at all the review sheet still lists every readable dish line with a blank price — tick what you want, type prices, import. Rows read without a price arrive unticked on purpose, so only what you confirm enters the menu.
  3. v1.1.71 — PDF reading fixed: PDF pages were being scanned on a transparent canvas, which the text recognizer reads as a blank image — now every page is painted on white paper first, so typed and scanned PDF menus produce items again. Pressing Import with nothing ticked now tells you, instead of doing nothing.
  4. In the review sheet that opens: un-tick any wrong line, tap a name or price to fix it, choose the category, add anything missed — then Import creates all of it in one tap. Items already on the menu are skipped automatically.
  5. Works best with English / Malay (Latin script) menus — lay them flat, fill the frame, good light. A PDF export of the menu is the most reliable scan. Urdu-script menus cannot be read by any on-device scanner, so type those manually.
  6. Menu tab → add categories (e.g. Drinks, Mains) and products with photo, price and SKU.
  7. Add modifiers per product: Size (small / large), Spice level, and priced Add-ons.
  8. Link a product to a stock item so sales deduct inventory automatically.
  9. Deleting a category asks for confirmation and moves its dishes to Uncategorized — it never wipes the products. Deleting a dish also asks first.
  10. Long-press a product on the order screen to 86 it (mark unavailable) — it greys out everywhere instantly.
  11. Currency symbol is configurable in Bill profile; every price uses it.

اردو

  1. 1.1.65 کا نیا فیچر — مینیو اسکین: مینیو ٹیب → اسکینر آئیکن → مینیو کی تصویر لیں (یا مینیو کی PDF اپ لوڈ کریں)۔ نام، قیمتیں اور کیٹگریز فون پر ہی پڑھے جاتے ہیں — انٹرنیٹ کی ضرورت نہیں، کچھ بھی کہیں بھیجھا نہیں جاتا۔

  10. آرڈر اسکرین پر پروڈکٹ کو دیر تک دبائیں تو 86 ہو جاتی ہے (دستیاب نہیں) — ہر جگہ فوراً۔

7 · Payments & split payment ادائیگیاں اور تقسیم ادائیگی

English

  1. Tap Pay on the ticket → pick the method: Cash, Card, Wallet, Other or Complimentary.
  2. Cash: use the keypad, Exact fills the due, change is shown. Card/wallet: tap and close.
  3. Tip can be added (none / 5% / 10% / 15%) before closing.
  4. Split payment: switch it on, choose a second method and its amount — e.g. cash 300 + card 500.
  5. Both methods print on the receipt and appear in the payment breakdown reports.
  6. The cash drawer opens only if any part of the sale is cash.

اردو

  1. ٹکٹ پر Pay دبائیں → طریقہ چنیں: کیش، کارڈ، والٹ، دیگر یا مفت۔
  2. کیش: کی پیڈ استعمال کریں، Exact پوری رقم بھرتا ہے، باقی رقم دکھتی ہے۔ کارڈ/والٹ: دبا کر بند کریں۔
  3. بند کرنے سے پہلے ٹپ شامل کریں (نہیں / 5% / 10% / 15%)۔
  4. تقسیم ادائیگی: آن کریں، دوسرا طریقہ اور اس کی رقم لکھیں — مثلاً کیش 300 + کارڈ 500۔
  5. دونوں طریقے رسید پر پرنٹ ہوتے ہیں اور رپورٹس کی ادائیگی تفصیل میں آتے ہیں۔
  6. کیش دراز صرف اس وقت کھلتی ہے جب سیل کا کوئی حصہ کیش ہو۔

8 · Cash drawer کیش دراز

English

  1. Plug the drawer's cable into the receipt printer's RJ11 (kick) port. No extra app or driver is needed.
  2. Main → More → Hardware → Cash drawer → switch on Open on cash payments.
  3. Tap Open drawer now to test.
  4. From now on: cash sale → drawer pops before the receipt prints. Card / wallet / other → drawer stays shut.
  5. If a station uses its own printer (section 9), the drawer kick goes through that printer.

اردو

  1. دراز کی کیبل رسید والے پرنٹر کے RJ11 (کِک) پورٹ میں لگائیں۔ کوئی الگ ایپ یا ڈرائیور نہیں چاہیے۔
  2. Main → More → ہارڈویئر → کیش دراز → کیش ادائیگی پر خود کھلے آن کریں۔
  3. ابھی دراز کھولیں دبا کر ٹیسٹ کریں۔
  4. اب: کیش سیل → رسید سے پہلے دراز کھلتی ہے۔ کارڈ / والٹ / دیگر → دراز بند رہتی ہے۔
  5. اگر کوئی اسٹیشن اپنا پرنٹر استعمال کرے (سیکشن 9) تو دراز اسی پرنٹر سے کھلتی ہے۔

9 · Printers & receipts پرنٹرز اور رسیدیں

English

  • Shop printers (Main): More → Hardware → Printers. Add LAN (IP + port 9100) or Bluetooth ESC/POS printers and assign each to a role (kitchen, cashier…).
  • Every station's own printer: tap the printer icon in the station's top bar. Pick a Bluetooth printer or type a LAN IP. The station then prints everything itself, independent of Main.
  • Bluetooth printing (v1.1.68) now works with any Bluetooth printer — old Classic (SPP) models like the common 58mm portables, and modern Low-Energy ones. Pair the printer once in Android settings (PIN 0000 usually), pick it in the printer sheet, and print. The Auto / Classic / LE chips let you force a link type if a picky printer needs the nudge; error toasts now quote the printer's real complaint.
  • These printers serve one connection at a time: while your station has a Bluetooth printer selected, Order Flow holds that link open like a real POS — so back-to-back prints (and the Test button) always reach the printer. Use Use shop printer to let it go.

English

  • 1 · Open a room (Main only). More → Plan extras → Cloud networking → Open cloud room (custom plan). The sheet shows a QR, a big JOIN CODE, and the full pairing text underneath.

Nothing is ever re-typed.

Every message is encrypted by your devices before it leaves them, deleted once all your devices have read it, and expires on its own in about 30 minutes even if nobody reads it. Shop data lives only on Main's device — backups stay entirely in your hands (§17).

If a room will not open, the message now names the true reason: license (the key is not on a cloud-enabled plan — message Jathol), relay (server hiccup — try again in a minute), or network (that phone has no internet). Mid-shift, an amber line "Relay unreachable — retrying automatically" (1.1.67) means only the corridor is jammed — your work stays safely queued on the device.
  • Keep the pairing sheet private. That QR and OF1 text are the key to your open room — anyone holding them can join while it stays open. Do not photograph it into public chats. When service ends, Close cloud room: closing wipes the room, and re-opening issues fresh credentials, so any old pairing stops working instantly.
  • Two-minute field test (do it once, calm): pair a station, put it on mobile data with Wi‑Fi switched off, send a test order — it lands on Main in seconds. Now you trust the fallback before the night you actually need it.
  • Guest table QR (§20) stays local on purpose — this section is for your own devices only, never for public traffic.

  5. Printing from a laptop Main: More → Printers offers Windows printers (any printer installed in Windows — USB thermal printers work with the built-in “Generic / Text Only” driver) and LAN / Wi-Fi (network ESC/POS on port 9100). Test print from the same sheet.
  6. QR guest ordering, backup/restore, reports, broadcasts all work identically — the guest ordering page is still served by Main, now from `http://LAPTOP-IP:8787/order`.
  7. First run — the blue SmartScreen popup (“Windows protected your PC / publisher unknown”): this appears because the app is not signed with a paid certificate yet. Click More info → Run anyway once — it is safe, and Windows stops showing it after the file builds trust (a paid certificate will remove it entirely later).
  8. Closing & reopening: the shop server lives inside the app, so it stops when you close the window (nothing keeps running in the background — the program fully exits) — and it restarts itself automatically a few seconds after you open the app again. If the top bar ever still says Server stopped, tap that chip once to start it. Phones and tablets reconnect on their own.
  9. Updating to a newer Windows release later: the newest ZIP is always on the download page. Close the app, download the new ZIP and extract it over the existing folder (or anywhere new) — everything you created (menu, sales, settings, printers) is stored in your Windows user folder (Documents + AppData), not inside the ZIP, so nothing is ever lost. No uninstalling needed. If Windows refuses with “folder in use” while extracting, the app is still running: close the order_flow.exe window first (no window? → Task Manager → order_flow.exe → End task), wait 3 seconds, then extract again — an open File Explorer window inside the same folder can also trigger it, so close that too.
