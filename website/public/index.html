Built for service

One Main phone. A whole floor of stations.

Order Flow is not a cloud till. The licensed Main device is the shop server. Tablets and phones connect on the same Wi‑Fi. If the internet drops, the shop still sells — and on custom plans, an encrypted cloud relay keeps every station in sync even when the shop Wi‑Fi itself dies, with no shop data ever stored in the cloud.

Kitchen fire

Send to kitchen prints the slip from Main and alerts the pass with sound, vibration and a banner.

Roles that fit

Manager, order taker, kitchen, cashier, driver, stock, front desk, specialist — cover from Main when you need to.

Wi‑Fi down? Service goes on

Custom plans get cloud networking: Main opens an encrypted room, each station joins on its own mobile data. Orders queue offline and merge automatically — the shop never stops. (Your data stays on Main; the cloud is only a corridor.)

Your face on the QR page

Give guests an ordering page with your shop's name, tagline, hours, WhatsApp button and colour — a beautiful animated menu that works on every phone, Urdu included. A custom-plan touch.

User Guide

Questions shops ask

Clear answers.

Does my sales data go to the cloud?

No. Tickets, menu and stock live on Main. The website only checks the license and serves this app file.

What if the internet drops?

Selling continues on shop Wi‑Fi. Stations can queue work and flush when Main is reachable. License has an offline grace window.

How do I install the app?

Download from this page on your Android phone, then allow install from this site when Android asks. Jathol will advise you when a store listing is available.

Can I try before I buy?

Yes. Use the 3-day trial form. WhatsApp opens with your details so Jathol can issue a trial key.

How do I buy a key?

WhatsApp @Jathol_Jutt with your name, business, email and phone. Jathol issues the 16-character key.

What does it cost?

Starter is RM 79/month and Growth is RM 149/month; large shops get custom pricing. See the Plans section — the license decides which features your key unlocks.

What hardware does it work with?

Any Android phone or tablet, LAN or Bluetooth ESC/POS thermal printers, barcode guns (USB/Bluetooth or the built-in camera scanner), and a cash drawer plugged into the receipt printer's RJ11 port.

Where do I learn every feature?

The full step-by-step guide is on the User guide page — updated with every app version.
