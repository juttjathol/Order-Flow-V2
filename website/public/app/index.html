Print — Apple + Android

iPhone uses Apple’s system print dialog (AirPrint incl. Bluetooth AirPrint printers). Android can also pair raw Bluetooth. If this iPhone has no printer, tick “Relay-print” — the job rides the encrypted room to a station that has a printer.
